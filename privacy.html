TopSSH 隐私政策

生效日期：2026 年 9 月 18 日 · 适用于 iOS 与 iPadOS

核心隐私承诺

  • 零个人数据收集：无需注册中心化账号，无第三方统计分析或广告 SDK。
  • 本地钥匙串保护：密码与私钥仅存储在系统安全钥匙串（Keychain）中。
  • 端到端自建同步：云同步仅连接用户自有的 WebDAV / S3 服务，数据本地强加密后方离开设备。
  • 无击键监控：终端所有交互直接走 SSH 安全加密信道，本地不留存亦不上报任何击键流。

1. 我们收集的信息

TopSSH 是一款本地优先（Local-First）的服务器管理与终端工具。在设计上，我们坚持最小化数据接触原则：

  • 零个人身份信息：我们不收集、不存储、亦不出售您的个人姓名、手机号码、电子邮件、设备唯一标识符（IDFA / IDFV）或 IP 地址。
  • 零第三方分析与追踪：应用内未集成任何第三方统计分析、行为追踪或广告 SDK（如 Google Analytics、Firebase、Adjust、Facebook SDK 等）。
  • 零网络遥测：App 不存在任何“向开发者服务器发送使用情况数据”的后台埋点机制。

2. 凭据与安全存储机制

保护您的服务器连接凭据是 TopSSH 的第一要务：

  • 系统钥匙串隔离：所有保存的 SSH 登录密码、私钥、私钥密码短语（Passphrase），均直接写入操作系统级安全钥匙串（iOS Keychain）。
  • 访问策略：凭据均设置了 kSecAttrAccessibleWhenUnlockedThisDeviceOnly 安全属性，这意味着凭据在设备锁屏时完全无法被解密访问，且凭据绝不会跟随 iCloud 备份漫游至非受控设备。
  • 生物识别前置确认：在连接已保存的服务器前，App 会调用系统级 Face ID / Touch ID 或设备锁屏密码进行身份核验，杜绝未授权持有设备者直接连接服务器。

3. 终端会话与网络通信

  • 端到端安全 SSH：App 内终端基于标准 OpenSSH / SwiftNIO SSH 协议与您指定的目标服务器建立点对点加密通道。数据交互仅发生在您的设备与目标服务器之间。
  • 无键盘记录与中转：终端界面的每一次敲击直接转化为 PTY 原始字节并由 SSH 加密传输，TopSSH 不会以任何形式记录、镜像或拦截您的终端命令与输出内容。

4. 云同步服务说明

TopSSH 提供可选的多设备数据备份与同步功能：

  • 去中心化与自建存储：TopSSH 不提供中心化存储服务器。同步仅支持用户自行拥有的 WebDAV 或 AWS S3 兼容对象存储。
  • 端到端高强度加密：同步快照在离开您的设备前，已在本地使用派生密钥（PBKDF2 结合 AES-GCM-256）完成加密。云存储服务商仅能保存密文快照，无法窥探或解密您的主机列表及私钥信息。
  • 不安全明文网络防护：默认禁止明文 HTTP 同步连接，仅在用户显式理解并勾选确认风险后方可放行。

5. 设备系统权限使用说明

  • 本地网络权限（Local Network）：用于检测局域网内的 SSH 服务器是否在线（轻量级 TCP 握手探测，不发送任何登录数据或业务流量）。
  • Face ID / 生物识别权限：用于在发起 SSH 连接前核实设备持有者身份。生物特征数据完全在 Apple 硬件级安全飞地（Secure Enclave）中处理，App 无法获知或保存原始生物识别数据。

6. 儿童隐私

本应用面向广大运维工程师、开发者与系统管理专业人员，不针对亦不会有意收集 13 周岁（或所在司法管辖区规定的适龄儿童）以下未成年人的任何个人信息。

TopSSH Privacy Policy

Effective Date: September 18, 2026 · Applicable to iOS & iPadOS

Core Privacy Commitments

  • Zero Personal Data Collection: No account registration, no third-party tracking, analytics, or ad SDKs.
  • Keychain Security: Passwords and private keys are secured exclusively in iOS Keychain.
  • End-to-End Encrypted Cloud Sync: Sync runs only against your self-hosted WebDAV / S3 storage; data is encrypted before leaving your device.
  • Zero Keystroke Logging: Direct encrypted SSH transport with zero telemetry or keystroke logging.

1. Information We Collect

TopSSH is a local-first SSH client and server management workbench. We adhere to the strict principle of zero data collection:

  • No Personal Identifiable Information (PII): We do not collect, process, or sell your name, phone number, email address, IP address, or device identifiers (IDFA/IDFV).
  • No Third-Party Analytics or Trackers: TopSSH contains no third-party analytics, tracking libraries, or advertising SDKs (e.g., Google Firebase, Adjust, Facebook SDK).
  • Zero Telemetry: The application does not communicate with any developer-hosted telemetry servers.

2. Credentials and Secure Storage

Protecting your connection credentials is our highest priority:

  • System Keychain Isolation: Saved server passwords, SSH private keys, and passphrases are written directly to the secure iOS Keychain.
  • Access Control: All items are tagged with kSecAttrAccessibleWhenUnlockedThisDeviceOnly. Credentials cannot be accessed while your device is locked and will never be backed up to unmanaged iCloud targets.
  • Biometric Protection: Before connecting to a saved server, TopSSH requires Face ID, Touch ID, or your device passcode.

3. Terminal Sessions and Network Communications

  • Direct Encrypted SSH: Terminal connections communicate directly with the target server via OpenSSH / SwiftNIO SSH protocols without intermediate proxying.
  • No Keystroke Logging: Keystrokes are passed straight to the PTY byte stream. TopSSH does not log, mirror, or capture any command input or terminal output.

4. Cloud Synchronization

  • User-Controlled Endpoints: TopSSH does not host a centralized synchronization server. Cloud sync works exclusively with your self-hosted WebDAV or S3-compatible endpoints.
  • Client-Side Encryption: All sync snapshots are encrypted locally using PBKDF2 and AES-GCM-256 before leaving your device. Storage providers see only ciphertext.
  • Cleartext Network Protection: Insecure cleartext HTTP connections are rejected by default unless you explicitly acknowledge the risk.

5. Device Permissions

  • Local Network: Used exclusively to probe server reachability via lightweight TCP connection checks without sending any login data.
  • Face ID / Biometrics: Used to verify device owner identity before SSH connection establishment. Biometric data is managed entirely within the Secure Enclave.

6. Children's Privacy

TopSSH is designed for software developers and system administrators. We do not knowingly collect any personal data from children under the age of 13.
